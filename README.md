# IITH Coding Challenge — Meme Multimodal Sentiment Analysis

Playground challenge from **IIT Hyderabad & TalentSprint (AI and Emerging Technologies)**: build a **multimodal sentiment classifier** for meme images using both visual and text features.

## Submission artifact

The only deliverable for evaluation is the Colab notebook:

**`AIET_PlayGround_Challenge_Colab_Notebook_v8.ipynb`**

All model development, training, and inference code must live in that notebook. Do not rely on separate local Python modules or scripts for the graded submission.

## Workflow

1. Open the notebook in **Google Colab** (or the environment specified by the program).
2. Implement and iterate entirely inside the notebook cells.
3. Run end-to-end and verify outputs meet challenge requirements.
4. Submit the completed notebook for evaluation.
